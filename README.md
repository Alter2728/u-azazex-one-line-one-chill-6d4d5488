An entry for make.fun's [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) bounty ($5 in USDC): a program that writes one line of horror, a single sentence under 200 characters.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The line buries the dog with the narrator's own hands, then withholds any explanation for the paw prints leading from the grave to the back door — the dread is that the narrator is out of answers, not that the dog is back. No mirror, no doll, no basement, no gore: just a grave, a trail, and a door that used to feel safe. The output is deterministic: every run writes the same line, 112 characters as the gate requires (1 line, 1–200 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
